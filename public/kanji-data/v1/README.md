# Kanji stroke data (v1)

`strokes/<codepoint>.json` holds the stroke order of one kanji (for example
`065e5.json` is 日), in KanjiVG's 109×109 box:

```json
{ "strokes": ["M…", "…"], "numbers": [[x, y], …], "groups": [{ "element": "日", "from": 0, "to": 4 }] }
```

Generated by `scripts/kanji/build.py`. Bump the folder (`v2`) and
`KANJI_DATA_VERSION` in `src/api/services/kanjiService.ts` when the data is regenerated.
