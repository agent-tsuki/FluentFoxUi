User decisions:
- **Same home for everyone.** Signing in changes only the words and the one button ("Continue · <position>").
- **Promotion:** minimal and calm, try-it first.
- **Hero:** a try-it widget (read あ, い, う, then the word あい).
- **Delivery:** mock-ups first (HomePage, HomeMobile, TryKana, FactStrip, WhatsNew and PathRail in the design system), then build once approved.

Checked facts: the site has no ads; the voices are AivisSpeech text-to-speech (never say "native").
